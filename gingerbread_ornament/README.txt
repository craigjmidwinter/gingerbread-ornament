Gingerbread Ornament - Blender add-on
=====================================

Turns a line-art / colouring-page image into a multi-colour gingerbread
ornament (cookie + piped icing + coloured flood icing + hanging hole) and
exports a 3MF that opens in Bambu Studio with every filament colour set.

Requirements: Blender 5.1 or newer, Bambu Studio. Multi-colour printing needs
an AMS (one AMS = 4 colours). The built-in printer settings are for a
Bambu Lab P1S with a 0.4 mm nozzle.

Install: Blender > Edit > Preferences > Get Extensions > the small arrow menu
(top right) > Install from Disk... > pick the .zip. Then open the 3D Viewport
sidebar (press N) and click the "Gingerbread" tab.

Quick start:
  1. Images: set "Line Art" to your black-line drawing.
  2. Click "Generate Ornament".
  3. Colours: click "Add Filament", then click regions in the viewport to
     paint them. Esc or right-click to stop colouring.
  4. Export: click "Export 3MF..." and open the file in Bambu Studio.

Several images at once: in "1. Images" switch to "Several Images", click +
and pick several line-art files (each becomes one ornament; select one in
the list to set its title or a coloured version). Generate builds them side
by side with ONE shared set of filaments: paint any of them with the same
slots. Max Filaments counts the whole set. In "4. Export", "Export Plate
3MF..." puts every ornament on one plate in one file; "Export Each 3MF..."
writes one file per ornament into a folder. Every file gets the same
filament list and slot numbers, so one AMS setup prints them all.

Known limit: Very fine lines in a drawing (under about 0.4 mm at print size, like fur strokes) can come out too thin to print; use bolder outlines or a larger size.

The full guide is in the README that came with your download.
